# Taikeron Launcher 0.4.16 — publication stable

- Intégration de Taikeron Map Chooser (TMC) comme troisième produit du Launcher.
- Identité visuelle et logo TMC dans la navigation.
- Gestion du runtime TMC : installation, mise à jour, réparation, désinstallation et contrôle d’intégrité SHA-256.
- Partage de la racine de cartes `TAIKERON_MAPS_ROOT` avec TL et TMB.
- Préparation de la distribution publique directe WMS de TMC, sans dépôt DEV.

La présence de TMC dans le Launcher ne signifie pas encore que son binaire public soit disponible : la publication WMS de TMC constitue une opération distincte.

Publication Launcher déclenchée par le message de commit `Release Launcher 0.4.16` selon le workflow Windows canonique. Les archives de mise à jour et leurs empreintes sont générées par GitHub Actions.
